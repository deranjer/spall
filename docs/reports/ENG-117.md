# ENG-117 evidence — interactive ecology showcase

## Scope

Added a client-local rendered showcase for the first vegetation lifecycle. It runs the ecology model against a private `Simulation` and generated terrain, renders the existing voxel world, and provides pause, single-interval stepping, bounded time multipliers, grass harvest, branch cut, and root destruction controls. This is an inspection fixture; it does not connect to a server or persist ecology state.

## Run

```powershell
cargo run -p sandbox --features client --bin sandbox-client -- --ecology-demo
```

Space pauses/resumes; `.` steps one interval while paused; `+`/`-` selects 1x/4x/16x; H harvests grass; B cuts a grown branch; X destroys the root. WASD/QE fly; click captures the mouse and Escape releases it. The HUD displays ecology time, speed, biomass, plant stage/count, and seeds.
