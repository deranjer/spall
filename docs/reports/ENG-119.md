# ENG-119 — Water look

Presentation-only follow-up to ENG-105. The simulation, protocol and saves are
unchanged; the client draws replicated water differently.

## What changed

- **Surface sheet.** `spall_render::water::build_water_surface` turns each
  keyframe's columns into one heightfield: every grid corner takes the mean
  surface of the wet columns around it, so neighbouring columns of different
  heights meet without a step. Triangles are flat-shaded (voxel look), level
  cells merge greedily into large quads, and a wall is added only where a
  column has no wet neighbour.
- **Height field.** `WaterField` stores one surface height per quarter-metre
  column and is bound to the opaque shader (`@group(0) @binding(4)`, read with
  `textureLoad`). It drives underwater fog, depth dimming and caustics for any
  fragment, from above or below.
- **Shader (`opaque.wgsl`).** Per-channel absorption (red first) with the
  fogged distance snapped to 0.25 m; sun/sky dimming with depth; Worley-vein
  caustics on a 0.25 m grid stepped at 4 fps; `fs_water` for the sheet (sky
  mirror and sun glint from above, Snell's window with a total-internal-
  reflection ring from below); a faint per-voxel grain on both faces
  (`WATER_VOXEL_HINT`).
- **Client.** `spall_client::water_look` builds the sheet and field for the
  terrain window from replicated keyframes. The old translucent-box path is no
  longer fed in the interactive window (the debug viewer still has it).

## Checks

- `cargo fmt --all --check`: clean.
- `cargo clippy --workspace --all-targets --all-features -- -D warnings`: clean.
- `cargo test --workspace --all-features --no-fail-fast`: all pass except
  `sandbox::dam_gate_replication::a_real_client_sees_the_dam_gate_open_after_the_admin_command`,
  which fails identically on unmodified `main` (client replica hash differs
  from the server's; server hash identical on both). Not caused by this change.
- `cargo test -p spall_render -- --ignored` (real GPU): pass, including
  `water_look_gpu`, which writes review frames to `.local/runs/water-look/`
  (above, under water, looking up, low angle, still water).

Measured: none. The GPU test asserts the underwater view is blue-green and the
frame is finite; the look itself was judged by eye from those frames and in the
live window by the requester. No frame-time measurement was taken.

## Limits and next work

- Only the highest wet run in each column is drawn; water under an air gap in
  the same column is not.
- Fog and caustics use one height per quarter-metre column, so a stepped surface
  can mis-tint a sliver of a bank wall.
- No waterline effect while the camera crosses the surface.
- Tuning constants (`WATER_ABSORB`, `WATER_BAND_M`, `WATER_VOXEL_HINT`, scatter
  colour) were chosen by eye.
