# ENG-190 - W5: living vegetation at 1 km

Ecological placement, new medium forms, raised caps, a compact version 3 save and
interest-based vegetation replication. Rules and the numbers table are in
`docs/worldgen.md` ("Living vegetation at 1 km"); wire notes in
`docs/protocol.md`. This file records what was measured and what was not.

## Measured (release, natural seed 1, 4096 cells; `vegetation_scale` example)

| | value |
|---|---|
| trees / living ground plants | 8,651 / 10,080 (caps 24,576 / 32,768) |
| wood cells held in memory | about 690,000 |
| saved state | 0.39 MiB (5.75 MiB with the version 2 layout) |
| keyframe, whole world | 0.65 MiB (plants 578 KiB, raster 82 KiB) |
| keyframe, regional window | 7.9 KiB (4 bricks), 13.7 KiB (8), 24.2 KiB (16); raster adds about 82 KiB once per 10 keyframes |
| full keyframe build (worker thread) | 32 ms |
| state copy on the tick thread per keyframe | 0.73 ms (10.3 ms before shared skeletons) |
| `encode()` | 2.9 ms (7.6 ms before skipping per-cell checks) |
| `advance` per second of ecological time | mean 2.7 ms, worst 5.5 ms |
| vegetation generation | 1.23 s of a 10.5 s world start |

Per-biome counts at 4096 cells (trees / ground): Meadow 2,891 / 3,300; Pine forest
3,060 / 256; Boreal 1,158 / 686; Temperate forest 657 / 370; Riparian 579 / 364;
Alpine 246 / 142; Swamp 167 / 285; Steppe 0 / 3,011; Desert 0 / 696; Scree 0 / 146;
Beach 0 / 37 (first run before the shrub species were added; the totals above
are from the final run).

Tree density is about 9,500 per km2 of land, at the low end of the ticket's
10-20 thousand; Steppe has no trees by design (canopy 0.06).

## Tests added

- `spall_ecology`: compact save round trip and size, version 2 load and
  re-save, refusal of an older tree that does not match the skeleton rule,
  windowed frame contents, shrub/bush/herb forms (above the soil, coarse < full,
  bloom by season).
- `sandbox/tests/placement.rs`: canopy follows biome; stands have a dominant
  species; spacing and caps; understory gathers in shade; deterministic.
- `sandbox/tests/vegetation.rs`: a regional network client receives under a third
  of the plants a whole-world client does, and both receive keyframes.
- Existing vegetation, biome flora, gallery and network suites pass unchanged
  except two: one needed a 256-cell world (a 128-cell world no longer has an
  unripe tree) and the underwater count needed a higher ocean understory.

## Checks run

`cargo fmt --all`; `cargo clippy --workspace --all-targets --features sandbox/client
-- -D warnings` clean; `cargo test` for `spall_ecology`, `spall_server`,
`spall_client`, `spall_sim`, `spall_protocol` and `sandbox --features client` all

## Not run / known

- `cargo xtask check` and the full workspace test run; GPU capture and
  performance gates; a captured real natural world (the example captures show
  gallery specimens).
- Multi-client bandwidth was computed from encoded frame sizes, not measured on
  a live link; a moving regional client's window follows its player once a second.
- Tree density sits below the ticket's upper range; ground plants cluster under
  trees only in forest biomes (checked), not tuned elsewhere.
- Not done: Poisson-disc ecotone rules per species pair, riparian strips as a
  separate rule (riparian is placed by biome), seeding that follows canopy
  density at runtime (offspring still use the species' own spacing), growth of
  more than four wood cells per second across the world.
- Fair-work visits are bounded, so at 40,000 organisms each is visited about every
  80 s.
