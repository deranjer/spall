# ENG-191 - W6: editor preview layers, tuning and docs

Successor to the ENG-115/ENG-118 editor and vegetation notes for worldgen v4
(ENG-186..ENG-191). Rules and descriptions are in `docs/worldgen.md`; this file
records what was changed here, what was measured, and what was **not** run.

## Changed

- `spall_worldgen::debug`: `PreviewLayer` (Biome, Height, Moisture, Temperature,
  Water, Vegetation), `layer_rgba`, `layer_range`, `layer_swatches`,
  `vegetation_density`. The vegetation layer is an *estimate* from biome
  fertility and wetness, not a plant count. All layers read the `ColumnMap` the
  server builds.
- `tools/spall_editor`: the World Gen dialog picks the world (Natural, Showcase,
  Gallery; default Natural) and a layer; switching layers redraws the stored map
  without regenerating. Run in game passes the chosen preset to `xtask play`.
- `spall_worldgen::columns::natural`: the every-biome repair now blends climate
  into the painted patch and penalises lowland biomes, which removed a visible
  disc artifact (a painted Desert patch) in the temperature layer.
- Docs: `worldgen.md` (presets, thirteen biomes, hydrology, lazy ocean, gallery,
  vegetation v2, cover regrowth, editor panel), `architecture.md`, `protocol.md`,
  `tasks.md`.
