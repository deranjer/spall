# G1 CPU-side evidence — ENG-18

Date: 2026-09-08 (revised after PR #50 review)

The tracked `g1-networked-destruction` fixture drives two real `sandbox-client`
OS processes against a real `sandbox-server` over QUIC. Client 0 cuts the
load-bearing column to detach the beam, then fires a **body-targeted** cut at
the detached beam while it is still falling; both clients excavate opposite
ends of the floor concurrently. The harness passes only when:

- every one of the ten scripted cuts commits (`transactions_committed >=`
  the cut count — a run that quiesces early therefore fails);
- the server and both clients agree on the final canonical topology hash;
- each live client observes the beam move at least
  `minimum_body_displacement_m` (0.3 m) — a stationary snapshot no longer
  counts as "motion";
- the body-targeted cut is accepted against the detached body (that body
  loses solid cells afterwards).

## Measured runs

Windows 11, rustc 1.96.1, loopback QUIC. `body Δ` is the largest straight-line
distance either replica saw the detached beam travel; `body cut` is whether the
client-0 cut against the detached beam committed.

Both runs converge on the same hash, commit all ten transactions, and land the

did not require a brick repair request.

Reproduced clean 6/6 and under 2% loss 4/4 while preparing this revision.

## Physics fix folded in

Before this revision the scenario crashed intermittently (~1 run in 2) in
Rapier's CCD sweep (`rapier3d ...ccd/sweeps.rs: "No element at index"`) when
the terrain collider was rebuilt on a committed cut while the beam was still
in motion. No body in these scenes enables per-body CCD, so the server now
runs the built-in scene with the CCD solver pass disabled
(`PhysicsConfig::disable_ccd`, `max_ccd_substeps = 0`). Topology hashes and
tick counts are unchanged with the pass on vs off; only the panic is removed.
The projectile-CCD physics report (`spall_physics`, `ccd: true`) keeps the
pass and is unaffected.

## Scope and remaining gate work

This is CPU-side T11 evidence, not a complete G1 pass:

- **Single brick.** The scene is `spall_voxel::fixtures::bridge_scene`, which
  fits entirely inside brick `(0,0,0)`. It does not yet validate cross-brick
  structural support or brick-boundary ownership transfer; that needs a scene
  built on `cross_brick_bridge` (or a widened `bridge_scene`) and is left as
  follow-up.
- **Detached beam does not settle.** With the column gone and the terrain
  collider rebuilt on each cut, the beam keeps falling rather than resting on
  the floor (the pre-existing `late-join-collapse` scenario shows the same
  behaviour). The gate checks conservation and hash agreement, which hold;
  a "body comes to rest on remaining structure" case is still owed.
- **Workload.** No full 64 x 32 x 64 m / 60 s / 10-tool-requests-per-second
  workload, 64-brick collapse stress case, graphical clients, captures, or
  GPU timings. Those remain unrun and are not represented here.
