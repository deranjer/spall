# Item models

Hand-held item assets (ENG-254), generated by
`cargo run -p spall_editor --example items`. All use cell size code 1 (6.25 cm),
+Y up, origin at a bounding-box corner, materials `wood.oak` and
`stone.granite` carrying per-cell colours matched to
`examples/sandbox/assets/items/make_items.py`.

| asset | cells (x y z) | size |
| --- | --- | --- |
| shovel | 5 x 16 x 2 | 31 x 100 x 12 cm |
| axe | 3 x 14 x 5 | 19 x 88 x 31 cm |
| compass | 7 x 2 x 7 | 44 x 12 x 44 cm card |
| compass_needle | 1 x 1 x 5 | 6 x 6 x 31 cm |
| paper_note | 4 x 1 x 5 | 25 x 6 x 31 cm |
| stick | 10 x 4 x 1 | 62 x 25 x 6 cm |
| log | 7 x 4 x 4 | 44 x 25 x 25 cm |
| stone | 4 x 3 x 4 | 25 x 19 x 25 cm |

The compass needle's local origin sits at compass cell (3, 2, 1) and its pivot
is the middle cell's centre (subcells 128, 128, 640), so rotating it about +Y
at the compass centre swings it over the card.

Tests: `cargo test -p sandbox --test items`.


6.25 cm is the finest cell the format allows, so small items (compass, note) are larger than life; the item system should scale them to the held size.
